# 自動テストの使い方

Life Support の動作を、ブラウザで自動で確認するテストです(約30項目)。

## 準備(1回だけ)

1. Python をインストールします(3.9以上)。
2. 次の2つを実行します。

```
pip install playwright
playwright install chromium
```

## 実行

リポジトリの一番上のフォルダで、次を実行します。

```
python tests/smoke_test.py
```

「合格」「不合格」が、1項目ずつ表示されます。不合格があると、最後に、その数が出ます。

## 何を確認しているか

- 安全性: 入力した HTML 文字列、改ざんしたバックアップ、壊れたバックアップ
- 入力の検証: 金額・文字数
- バックアップの書き出しと読み込み
- 支出の編集、ダイアログのキーボード操作
- 今日使えるお金の計算、冷蔵庫の賞味期限の目安、日用品の季節による目安
- 今日の生活アシスト、レシートの二重登録の警告
- 画面幅(320〜1280px)で、横にはみ出さないこと
- ログイン・保存失敗・AI読み取り(**本物ではなく、代用品で確認**)
- アプリ化(ホーム画面に追加)と、ネットがないときの起動

## 注意

- Firebase と AI(Gemini)は、**本物のように動く代用品(スタブ)**で試しています。本物の Firebase のルール、ログイン、同期、AIの精度は、このテストでは、確認できません。
- スマートフォンの実機、カメラ、バーコードの読み取りも、このテストの範囲外です。
